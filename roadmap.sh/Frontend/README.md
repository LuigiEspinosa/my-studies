# Frontend Developer

## What is a Frontend Developer?

A frontend developer is a progressional who uses HTML, CSS, and JavaScript to design and build the visual and interactive elements of websites and applications that users engage with directly.

This developer is responsible for creating the user interface of a website to ensure it looks good and is easy to use, with a great focus on design principles and user experience.

As a frontend developer, you'll be working with the following technologies:

- **HTML**: The markup language used to create the skeleton of the page. All the information you want to show on a webpage will be laid out trough HTML.
- **CSS**: The Cascading Style Sheet language allows you to adjust the way in which the HTML elements are rendered, improving the visuals of your webpage.
- **JavaScript**: It allows you to add dynamism to your websites/apps. There is an alternative known as TypeScript, which is strongly typed superset of JavaScript.

### What skills are required for a Frontend developer?

1. Understanding the core technologies.
2. Understanding accessibility.
3. Version control systems.
4. Responsive design.
5. User experience (UX).
6. SEO.
7. RESTful APIs.
8. Testing and debugging.
9. Dev tools.
10. Frameworks.
11. Web performance.
12. TypeScript.
